Panduan penggunaan

  1. Lengkapi informasi karyawan. Foto bersifat opsional dan dioptimalkan secara otomatis.
  2. Gunakan Langsung untuk data dengan foto mini opsional, atau Ringkas untuk seluruh data teks tanpa foto. Kedua mode dapat langsung diunduh dan dipindai tanpa mengunggah file per karyawan.
  3. Klik Unduh QR Code untuk menyimpan PNG 2048 px. Gunakan Perbesar untuk dipindai saat memindai dari layar. Pratinjau hasil scan membuka data langsung.
  4. Agar profil terbuka di HP lain, unggah proyek ke GitHub Pages atau isi alamat publik yang sudah aktif pada pengaturan tautan QR. Unduhan PNG dinonaktifkan untuk alamat file lokal dan localhost.

Tautan berisi salinan data profil dan foto kecil. Periksa informasi dan bagikan melalui kanal yang sesuai.

Perubahan formulir menghasilkan QR baru. QR lama tetap berisi data sebelumnya. Unduh QR baru setelah mengedit profil. Data formulir tidak disimpan setelah halaman dimuat ulang.
